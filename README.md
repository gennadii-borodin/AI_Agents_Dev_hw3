### Принцип работы (шаг за шагом):

1. **Загрузка контекста** — `ContextLoader` читает JSON-файлы из `context/`
2. **Поиск релевантного контекста** — по ключевым словам находится релевантная информация
3. **CoT Prompt** — формируется системный промпт с инструкциями Chain-of-Thought
4. **Streaming вызов** — OpenAI API вызывается с `stream=True`
5. **SSE передача** — каждый токен отправляется клиенту через Server-Sent Events
6. **Рендеринг** — клиент отображает токены в реальном времени

## 🚀 Быстрый старт

### 1. Установка

```bash
cd ai_agent_project
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows

pip install -r requirements.txt
```

### 2. Настройка переменных окружения

```bash
export OPENAI_API_KEY="sk-your-key-here"   # Linux/Mac
export OPENAI_BASE_URL="https://api.openai.com/v1"  # опционально, для кастомного endpoint
```

```cmd
set OPENAI_API_KEY=sk-your-key-here        # Windows cmd
set OPENAI_BASE_URL=https://api.openai.com/v1
```

```powershell
$env:OPENAI_API_KEY="sk-your-key-here"     # Windows PowerShell
$env:OPENAI_BASE_URL="https://api.openai.com/v1"
```

> `OPENAI_BASE_URL` — опционально. По умолчанию `https://api.openai.com/v1`. Позволяет направлять запросы через прокси или кастомный gateway.

### 3. Запуск сервера

```bash
python -m api.server
# или
cd api && python server.py
```

Сервер запустится на `http://localhost:8000`

### 4. Тестирование

**Web UI**: Откройте `http://localhost:8000` в браузере

**CLI тесты**:
```bash
python test_client.py
```

**cURL (потоковый)**:
```bash
curl -X POST http://localhost:8000/chat/stream \
  -d "message=Расскажи о FlowAgent" \
  -d "use_cot=True"
```

**cURL (JSON)**:
```bash
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "Какие модели поддерживаются?", "use_cot": true}'
```

## 🧠 Chain-of-Thought (CoT)

Агент использует **5-шаговый CoT-процесс**:

```
[АНАЛИЗ]    — Анализ запроса, определение ключевых сущностей
[КОНТЕКСТ]  — Поиск релевантной информации в базе знаний
[РАССУЖДЕНИЕ] — Пошаговое логическое рассуждение
[РЕШЕНИЕ]   — Выбор оптимального ответа
[ОТВЕТ]     — Финальный ответ пользователю
```

CoT включается/выключается параметром `use_cot` (по умолчанию `true`).

## 📚 Контекстная система

Контекст хранится в JSON-файлах в директории `context/`.

### Структура `knowledge_base.json`:

```json
{
  "company": { ... },      // Информация о компании
  "technical": { ... },    // Техническая информация
  "faq": [ ... ],          // Часто задаваемые вопросы
  "prompts": { ... }       // Шаблоны промптов
}
```

### Добавление контекста:

1. Создайте новый `.json` файл в `context/`
2. Вызовите `POST /context/reload` или перезапустите сервер

## 📶 Потоковая передача (SSE)

Используется протокол **Server-Sent Events**:

```
Content-Type: text/event-stream

data: {"type":"context","content":"..."}
data: {"type":"token","content":"Т"}
data: {"type":"token","content":"е"}
data: {"type":"token","content":"к"}
data: {"type":"token","content":"с"}
data: {"type":"token","content":"т"}
data: {"type":"done","data":{...}}
```

Типы событий:
- `token` — очередной токен ответа
- `context` — найденный релевантный контекст
- `done` — завершение генерации
- `error` — ошибка

## 🔧 Конфигурация агента

```python
from agent.agent_core import AgentConfig, AIAgent

config = AgentConfig(
    model="gpt-4o-mini",      # Модель OpenAI
    temperature=0.7,           # Креативность (0.0 - 2.0)
    max_tokens=4096,           # Макс. токенов в ответе
    use_cot=True,              # Chain-of-Thought
    cot_depth=3,               # Глубина CoT
)

agent = AIAgent(config)
```

## 🛠 Устранение неисправностей

### Кнопка «Отправить» не работает / ничего не происходит

1. **Очистите кеш браузера** (Ctrl+F5) — после обновлений сервера может остаться старая версия страницы
2. **Откройте консоль браузера** (F12 → Console) и проверьте ошибки:
   - `SyntaxError: Invalid or unexpected token` — обновите страницу (кеш)
   - `Failed to fetch` — сервер не запущен или упал
3. **Проверьте терминал сервера** — там должно быть предупреждение если `OPENAI_API_KEY` не установлен

### Ошибка сервера 500 при отправке запроса

- **`OPENAI_API_KEY` не установлен** — задайте переменную окружения (см. Быстрый старт)
- **Неверный API ключ** — проверьте правильность ключа в OpenAI Dashboard
- **`OPENAI_BASE_URL` указан неверно** — если используете кастомный endpoint, убедитесь что URL корректен
- **Нет интернета** — агент требует подключения к облачной LLM

### Агент отвечает не на русском

- Системный промпт в `context/knowledge_base.json` → `prompts.system_prompt` содержит инструкцию отвечать на русском. Если вы изменили контекст — перезагрузите его через `POST /context/reload`

### Изменения в JS не применяются

- HTML-код веб-интерфейса встроен в `api/server.py` как Python-строка. После правок перезапустите сервер.
- Если используете `\n` в JS-строках — экранируйте их как `\\n`, чтобы Python не интерпретировал их как перевод строки.
